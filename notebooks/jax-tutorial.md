[`JAX`](https://docs.jax.dev/en/latest/) is an amazing library for automatic differentiation using `numpy`-like syntaxes.
It is extremely versatile, as it can be used for training neural networks, for heavy simulations on the GPU, for Bayesian 
inference and much more. Its ecosystem is growing exponentially, and libraries are being built for a lot of purposes. 
I cannot emphasize enough how useful it is, and how `JAX` was a game changer for me. In my lab, I gave two hands-on workshops, 
and I am sure that sharing this here can be useful for others as well.
